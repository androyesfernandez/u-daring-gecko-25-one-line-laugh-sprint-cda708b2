A tiny entry for [u-daring-gecko-25-one-line-laugh-sprint-cda708b2](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2)
on make.fun: a program that writes a single original one-line joke about
everyday life — a delivery driver, a door, and a curtain — straight into
`/output/entry.txt`.

Run it with Node 22 and no network:

```sh
node main.ts
```

The line it writes is one sentence, no explaining, with the twist landing
in the last words: the narrator asks for a contactless drop-off, then hides
and watches it happen anyway.
